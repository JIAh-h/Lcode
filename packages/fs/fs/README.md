# @lcode/fs

> 能力层接口包（文档 20 §6.1「文件」族，`ctx.fs`）：**只含类型、接口、事件声明**，不含实现。
> 路径规范化 + 工作区边界判定在**接口层统一**，实现层不得各自实现（20 §6.1）。

## 实现包

- `fs-local`：本机文件系统（批次 ⑤ 落地）
- `fs-sandbox`：受沙箱约束的文件系统
- `tool-fs`：把 `ctx.fs` 暴露给模型的消费包（`read` / `write` / `edit` / `glob` / `grep`，21 §3.1–3.5）

## Known Limitations

- 骨架版只定义接口与 `paths` 工具（规范化/工作区判定）；真实实现随批次 ⑤。
- 工作区外写入必须过审批接缝（C4），由 `interaction/approval` 注入。
