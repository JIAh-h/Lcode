# @lcode/agent-default-model

> 骨架层（文档 20 §5.5，`ctx.agentDefaultModel`）：**"当前用哪个模型"的唯一权威**。
> 稳定模块（允许加方法）。UI、CLI、协议服务三个入口共享同一状态（M1）。

## 职责

- `get(scope?)`：读取当前模型选择
- `set(sel, scope?)`：写入（会话内临时切换**不修改默认值**，但必须落盘为会话事件，M2）
- `watch(fn)`：订阅变化

## 不做什么

- 不解析凭据（那是 `credentials`）、不发起调用（那是 `llm`）、**不做自动路由**（D21，M3）。

## 不变量

| # | 不变量 |
|---|---|
| M1 | UI、CLI、协议服务三个入口读写的是**同一个状态**（不是三份各自维护的副本） |
| M2 | 会话内临时切换**不修改默认值**，但必须落盘为会话事件 |
| M3 | 不引入任何"按难度自动选模型"的逻辑（D21，重放一致性的前提） |

## Known Limitations

- 六层配置模型（D19：单次覆盖 > 会话选择 > 工作区预设 > 用户设置 > 适配器基座 > schema 默认）的
  逐字段合并解析在 `settings` 接入批次完成；本包当前提供单层 get/set 权威。
