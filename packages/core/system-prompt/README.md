# @lcode/system-prompt

> 骨架层核心（文档 20 §5.2，`ctx.systemPrompt`）：把"要告诉模型的一切"装配成
> 一次请求的 system 内容与工具 schema 列表。冻结模块（改接口走 ADR）。

## 职责

- `section(id, content)`：注册一个静态段落（返回 disposer）
- `context(id, fn)`：注册一个动态上下文（每次装配时求值；求值必须是纯函数且不得阻塞）
- `variable(name, resolve)`：声明变量的取值来源
- `tools(ids | fn)`：追加/收窄工具 schema（收窄是叠加的，不可放宽）
- `assemble(input)`：装配（纯函数语义）

## 不做什么

- 不发起请求、不决定用哪个模型、不缓存跨请求的装配结果。

## 不变量

| # | 不变量 |
|---|---|
| P1 | `assemble()` 对同一份日志与同一份注册集合**逐字节可复现**（I1 的另一半） |
| P2 | 段落顺序由 `order` 与注册顺序共同决定，**结果不得依赖并发注册的时序** |
| P3 | 动态上下文的求值不得产生副作用（不得写日志、不得触发工具） |
| P4 | 工具 schema 只可**收窄**不可放宽——子代理不能拿到父代理没有的能力 |

## Known Limitations

- 变量插值语法（`{{name}}`）在骨架中为字面替换，语法细节随 09 号文档定稿。
- 工具 schema 的收窄校验基于 id 集合；将来按完整 schema 做语义收窄校验（P4 强化）。
